Míralo funcionando

Esta es la librería de esta página, no una captura. Sube un archivo.

Por qué

Todo sistema de RR. HH. termina escribiendo a mano la misma lista de documentos pendientes. Aquí ya está resuelta, con los casos que duelen.

Vencimientos que avisan

Cada documento puede vencer (INE, licencia, constancias). Pasa a «por vencer» con aviso configurable y a «vencido» sin que nadie lo revise.

Requisitos por puesto

El chofer entrega licencia; el analista, no. Define los requisitos una vez y cada persona ve los suyos.

Revisión sin ventanas

Aprobar o rechazar con motivo, dentro de la misma lista, con teclado y avisos para lectores de pantalla.

Vista de equipo

A quién le falta qué, de menor a mayor avance, con búsqueda y CSV que Excel no puede usar como fórmula.

El mismo motor en tu API

nexus-expediente/motor calcula estados y avance sin DOM, para reportes y correos de «documentos por vencer».

Listo para tu bitácora

Cada cambio llega como un registro de auditoría: quién, qué, cuándo, antes y después. Ver cómo conectarlo.
